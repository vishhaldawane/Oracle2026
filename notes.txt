	I. by extending Thread class

		a. extend from Thread class
		b. override run() method ( and write ur logic)
		c. create object of your class of step a
		d. invoke the start() method of your object
			which will inturn invokes your run()

	II. by implementing Runnable interface

		a. implement from java.lang.Runnable interface
		b. mandatorily define the run() method of it
		c. create object of your class of step a
		d. create object of java.lang.Thread class and pass
			 your object of step a into its ctor

		e. invoke java.lang.Thread's object start() method
			which will invoke your run() method
